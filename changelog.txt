---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 2026-08-21
  Features:
    - Belt Planner tool. Drag a line one tile deep to set where the run starts and how many lanes
      wide it is, then click to run belts to that point. Each click continues from where the last
      one ended.
    - Builds several lanes in parallel, preserving the spacing of the opening drag.
    - Bridges obstacles with an underground pair that spans exactly the obstacle and no further. An
      obstacle too long for the chosen belt is refused rather than approximated.
    - Optional landfill over water, placed as tile ghosts, so water is never modified directly.
    - Belts can be built against their transport direction, from the destination back to the source.
    - Everything one click places goes into a single undo item, so one press of undo removes the
      whole run, landfill included.
    - Corners. Clicking off to one side runs the belts out along the anchor's axis and then turns
      once. Several lanes turn at staggered points so the bundle comes out of the corner still
      parallel and still the same width, and the anchor turns with it so clicks keep chaining.
    - Trees and rocks standing in the way are marked for deconstruction rather than blocking the
      run. Ctrl+click extends that to your own buildings, which are never cleared without it.
    - Live preview follows the cursor: belts, tunnel mouths, landfill and anything to be removed,
      with blocked tiles outlined in red before you commit. The opening drag shows its squares as
      you make it, green while the shape is a legal anchor and red when it is not.
    - A window while the tool is held, showing the belt tier and the three decisions the run
      depends on: tunnel under obstacles, landfill over water, and clear your own buildings. The
      mod settings are now only the defaults those switches start at.
    - Splitters. Shift+right-drag ends a run with a row of splitters instead of belts, pairing lanes
      1-2, 3-4 and so on and facing them along the flow. Everything leading up to them - the belts,
      the tunnels, the clearing - behaves exactly as it would have. The bundle has to be an even
      number of lanes wide and the run straight, and both are refused rather than approximated.
    - Shift+B steps through the belt tiers without leaving the tool.
  Bugfixes:
    - Fixed a second run over the first being refused, and the planner then trying to tunnel under
      its own belts. The cursor probes were being surveyed as obstructions, which forced a
      buildability check on every tile, and that check refuses a tile already holding a ghost.
    - The tool no longer draws a box per tile. The anchor and the opening drag each get one outline
      round the whole shape, and the cursor probes were shortened to a narrower range of sizes so
      fewer selection boxes flicker past as the pointer is tracked.
    - Fixed a crash while previewing a long run through trees. Past a few hundred pieces the preview
      switches to a summarised form, and that form assumed every piece named a prototype; something
      marked for removal names an entity instead. Both forms now share one place that decides how a
      piece is drawn.
    - Fixed clicking the tool window arming a drag from wherever the window sat over the map.
    - Fixed the tile shared between one run and the next keeping the old belt tier or the old
      direction after changing either mid-chain.
    - Added a tips and tricks entry under Ghost building, since the tool has eight gestures and
      nothing in the game explained any of them.
    - The preview now fails soft. It redraws on every cursor movement and is purely cosmetic, so a
      fault in it switches the preview off for that player and says so, rather than ending the
      session. Putting the tool away and taking it out again retries.
  Optimizations:
    - Planning a corner was about seven times more expensive than it needed to be. The world was
      surveyed over the rectangle enclosing the run, and the enclosing rectangle of an L is almost
      all empty space: a 100x60 corner read some 6000 tiles to plan a few hundred. Each leg is now
      surveyed as its own band. Measured over a 483-tile corner, 16.6ms fell to 2.3ms, which
      matters because the preview re-plans every time the pointer crosses a tile and a tick is
      16.7ms.
    - Fixed the preview giving up once the cursor was far from the player. The invisible probes the
      tool uses to find the pointer were laid out around the character, so past roughly eighty
      tiles there was nothing to track and the preview simply stopped. The block now follows the
      pointer instead, is wider, and moves on before the pointer can reach its edge.
    - A run the tool cannot plan now says why, at the cursor, while you are still pointing. It used
      to just draw nothing, which looks the same as the tool being broken.
    - The opening selection is marked on the ground the way the copy tool marks one: a tinted wash
      drawn beneath entities with a border over it, rather than a thin outline that is easy to lose
      against a busy base. The starting tile is marked the moment the button goes down.
  Info:
    - Everything is placed as ghosts. The tool never consumes items and never builds real entities,
      so it changes nothing in a savegame that was not already ordered.
